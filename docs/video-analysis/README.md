# 视频分析文档

本目录存放「立心之约 · 中学生人工智能微课十讲」视频的分析产物，**不含视频文件本身**。

## 目录结构

- `notes/` — 10 讲的精读笔记（基于视频画面与讲解内容整理，每讲一份 Markdown）
- `transcripts/` — 10 讲的逐字稿（带 `[MM:SS]` 时间戳，`t01.txt` ~ `t10.txt`）

## 用途

1. 后端 `ai-agent-service/video_transcripts.json` 由 `transcripts/` 切片生成，支撑视频伴侣（章节索引、播放位置上下文、三分钟导读）。
2. `notes/` 可作为教师备课参考与课程内容校对材料。
3. 视频文件存放于阿里云 OSS（`labsyssss` bucket），不在本仓库中。

## 注意

- 视频原始文件（`*.mp4`）与抽帧图片（`*.jpg`）均不纳入版本控制。
- 逐字稿为自动转写结果，可能有个别错字，已在使用侧做容错处理。
